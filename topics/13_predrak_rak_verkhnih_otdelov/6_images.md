# Тема 13. Предраковые состояния и рак пищевода и желудка — Изображения

## 13-01. Каскады канцерогенеза верхних отделов ЖКТ
Где в тексте: 1_full.md, раздел 5 «Патогенез»; 2_short.md, раздел 5.
Промт для генерации:
«Медицинская учебная схема, плоская векторная иллюстрация, белый фон, спокойная палитра (тёмно-синий, бирюзовый, серый, акценты коралловым), чёткие тонкие линии, без фотореализма и без крови. Формат: горизонтальный 16:9. Изображено: три горизонтальные дорожки одна под другой, в каждой 5 прямоугольных блоков слева направо, соединённых стрелками. Верхняя дорожка (желудок, бирюзовая): «H. pylori-гастрит» → «Атрофия» → «Кишечная метаплазия» → «Дисплазия» → «Аденокарцинома желудка»; над первыми двумя блоками коралловая скобка с подписью «Эрадикация наиболее эффективна». Средняя дорожка (пищевод, тёмно-синяя): «ГЭРБ» → «Пищевод Барретта» → «Дисплазия низкой степени» → «Дисплазия высокой степени» → «Аденокарцинома пищевода». Нижняя дорожка (серо-синяя): «Курение, алкоголь, горячие напитки, ахалазия» → «Хроническое повреждение» → «Дисплазия плоского эпителия» → «Плоскоклеточный рак пищевода». Слева от каждой дорожки маленькая пиктограмма органа (желудок, пищевод). Внизу отдельная плашка: «CDH1 → утрата E-кадгерина → диффузный рак без видимой предстадии». Подписи на русском языке, точный текст подписей: «H. pylori-гастрит», «Атрофия», «Кишечная метаплазия», «Дисплазия», «Аденокарцинома желудка», «Эрадикация наиболее эффективна», «ГЭРБ», «Пищевод Барретта», «Дисплазия низкой степени», «Дисплазия высокой степени», «Аденокарцинома пищевода», «Курение, алкоголь, горячие напитки, ахалазия», «Хроническое повреждение», «Дисплазия плоского эпителия», «Плоскоклеточный рак пищевода», «CDH1 → утрата E-кадгерина → диффузный рак без видимой предстадии». Шрифт без засечек, крупный, хорошо читаемый на телефоне.»

## 13-03. Алгоритм наблюдения при предраковых состояниях желудка
Где в тексте: 1_full.md, раздел 12 «Лечение»; 2_short.md, раздел 12.
Промт для генерации:
«Медицинская учебная схема, плоская векторная иллюстрация, белый фон, спокойная палитра (тёмно-синий, бирюзовый, серый, акценты коралловым), чёткие тонкие линии, без фотореализма и без крови. Формат: вертикальный 3:4. Изображено: блок-схема сверху вниз. Верхний блок: «ЭГДС высокого качества + биопсии по Сиднейской системе + эрадикация H. pylori всем». Ниже ромб «Есть дисплазия?». Ветка «Нет» ведёт к трём блокам рядом: «Атрофия/метаплазия только в антруме → наблюдение не нужно», «OLGA/OLGIM III–IV → ЭГДС каждые 3 года», «OLGA/OLGIM III–IV + рак у родственника → каждые 1–2 года». Ветка «Да» (коралловая) ведёт к ромбу «Видимый очаг?»: «Да → эндоскопическая резекция en bloc», «Нет, LGD → повтор с хромоэндоскопией, затем через 12 мес.», «Нет, HGD → повтор сразу, затем каждые 6 мес.». Сбоку отдельный блок серого цвета: «Аутоиммунный гастрит → ЭГДС каждые 3–5 лет». Внизу плашка: «Старше 80 лет без симптомов — наблюдение не начинать». Подписи на русском языке, точный текст подписей — как перечислено выше. Шрифт без засечек, крупный, хорошо читаемый на телефоне.»
