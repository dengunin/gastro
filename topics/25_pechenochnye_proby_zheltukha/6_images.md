Формат: горизонтальный 16:9. Изображено: вверху по центру крупная формула в рамке «R = (АЛТ / ВГН) : (ЩФ / ВГН)». Формат: вертикальный 3:4. Изображено: блок-схема сверху вниз. Верхний блок «Изменённые печёночные пробы». От него коралловая стрелка вправо к коралловому блоку «Красные флаги? → срочно / госпитализация». Вниз — блок «Анамнез: алкоголь, лекарства и БАД, метаболические факторы, нагрузка». Левая колонка «R ≥ 5 — гепатоцеллюлярный»: «HBsAg, anti-HCV», «ANA, ASMA, IgG», «ферритин, насыщение трансферрина», «церулоплазмин, тТГ, ТТГ, КК». Средняя колонка «R ≤ 2 — холестатический»: «УЗИ: протоки?», ветка «расширены → МРХПГ / ЭУС / КТ, хирург», ветка «не расширены → AMA, лекарства, МРХПГ». Правая колонка «Изолированные отклонения»: «ГГТ → алкоголь, метаболизм», «ЩФ без ГГТ → кость, беременность», «АСТ → КК, макро-АСТ», «непрямой билирубин → гемолиз? → Жильбер». Колонки сходятся в нижний блок «УЗИ + FIB-4 → эластография», затем два итоговых блока: «Наблюдение у терапевта» и «Гастроэнтеролог / гепатолог». Формат: вертикальный 3:4. Изображено: дерево решений сверху вниз. Верхний блок «Повышен билирубин → фракции». Две ветви. Правая ветвь «Прямой» ведёт к блоку «УЗИ: протоки», от него две стрелки: коралловая «расширены → механическая желтуха → МРХПГ / ЭУС / КТ, хирург» и бирюзовая «не расширены → печёночные причины: гепатиты, ЛПП, ПБХ, сепсис; при нормальных ферментах — синдромы Дубина — Джонсона и Ротора». Внизу коралловая полоса «Лихорадка + боль + желтуха = холангит → экстренно». Подписи на русском языке, точный текст подписей указан выше. Шрифт без засечек, крупный, хорошо читаемый на телефоне.»
