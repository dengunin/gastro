## Как устранено моргание меню

В `tools/site_assets/navigation.js` добавлена навигация внутри темы. При первом открытии страницы меню уже содержит все оглавления. Нажатие на раздел загружает его HTML, после чего меняются только дочерние узлы `main`, заголовок документа, активные классы и видимость оглавлений. `aside#side`, его ссылки, шапка и нижняя навигация остаются теми же DOM-узлами. CSS-анимация перехода между документами удалена.

Повторно открытые страницы берутся из памяти текущей вкладки. Конкурирующие загрузки отменяются. Поддерживаются обычные якоря, прямое открытие страниц, «Назад/Вперёд», поиск, переход из разбора теста в полный материал и возврат к сохранённой попытке. При уходе с теста останавливаются его таймер и обработчик клавиатуры; при возврате состояние восстанавливается из хранилища браузера.

Этот механизм подключён ко всем 43 темам. Расширенное оформление в этой работе перенесено только на тему 2. Переход между разными темами остаётся обычным переходом по HTML-ссылке. Обычные ссылки также служат запасным вариантом при ошибке загрузки или открытии через `file://`.

## Локальный просмотр

Из папки `github-pages`:

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory site
```

Откройте `http://127.0.0.1:8000/topics/02_farmakologiya/index.html`. Для проверки переходов используйте HTTP, поскольку браузер ограничивает загрузку HTML из соседних файлов при открытии через `file://`.
